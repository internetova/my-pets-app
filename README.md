# My Pets App

Public repository of the **My Pets** app — a pet care diary.

The app helps you keep track of your pets: profiles, weight, vet visits,
prescriptions, medications and other events. All data is stored locally on the
user's device — the app has no server of its own.

# Приложение "Мои питомцы"

Публичный репозиторий приложения **My Pets** — дневника заботы о питомцах.

Приложение помогает вести учёт питомцев: профили, вес, визиты к ветеринару,
назначения, лекарства и другие события. Все данные хранятся локально на
устройстве пользователя — у приложения нет собственного сервера.
