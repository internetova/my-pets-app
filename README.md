# my-pets-app

Публичный репозиторий приложения **My Pets** — дневника заботы о питомцах.

Приложение помогает вести учёт питомцев: профили, вес, визиты к ветеринару,
назначения, лекарства и другие события. Все данные хранятся локально на
устройстве пользователя — у приложения нет собственного сервера.

  - [English version](https://internetova.github.io/my-pets-app/privacy-policy-en.html)
- **[Issues](https://github.com/internetova/my-pets-app/issues)** — сюда можно
